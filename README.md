Entry for the make.fun competition **A Day of One-Line Pitches**
(`u-ronigrv-a-day-of-one-line-pitches-12cd9bb3`).

The program writes one sentence — 193 characters — to `/output/entry.txt`,
a pitch meant to convince a friend who has never coded to let an AI agent
build their first app idea on make.fun:

> You've had that app idea for years — describe it in plain words, let an
> AI agent build the first version on make.fun, and if you don't love what
> comes back, you've lost nothing but ten minutes.

## Run

```sh
python3 main.py   # writes /output/entry.txt
```
